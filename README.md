# Folder Upload

WordPress の `wp-content/uploads` の中の好きなフォルダへ、ファイルやフォルダごとアップロードできるプラグインです。標準のメディアの「年/月」フォルダとは別に、決まった場所にファイルを置きたいときに使います。

## できること

- uploads の中のフォルダを選んで、ファイルを置く（フォルダをドラッグすると、中の構成ごと置けます）
- 置いたファイルをメディアライブラリにも登録する（選べます）
- 同じ名前のファイルがあるとき「別の名前で置く」か「上書きする」かを選ぶ
- ファイルの名前を変える。サイズ違いのファイルと、記事の本文の URL もまとめて書き換えます（メディアの詳細画面からも変えられます）

管理画面の「メディア → フォルダにアップロード」から使います。

## 安全のために

- 使えるのは管理者（`manage_options` を持つユーザー）だけです。送信のたびに nonce も確かめます
- 置き場所は uploads の中だけです。`..` やシンボリックリンクで外に出られないよう、実際のパスでも確かめます
- 置けるのは、画像・PDF・動画・音声・フォント・CSS・SVG の決まった拡張子だけです。拡張子に加えて、ファイルの中身（MIME・画像として読めるか）も確かめます
- PHP のコードが入ったファイルは置けません。SVG は script や外部の読み込みなど、危ないものが1つでもあれば断ります
- 名前を変えるときも拡張子は変えられません

## インストール

1. [Releases](https://github.com/donnma777/wp-folder-upload/releases) から Source code (zip) をダウンロード
2. WordPress の管理画面「プラグイン → 新規追加 → プラグインのアップロード」で zip を選び、有効化

## 動作環境

- WordPress 6.0 以上
- PHP 8.0 以上（`fileinfo` 拡張が必要）

## 注意

- 「上書きする」を選ぶと、元のファイルは戻せません
- 管理画面は日本語のみです
- 個人で作ったものです。サポートや不具合対応のお約束はできません
